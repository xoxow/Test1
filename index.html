데이터 연결

이 화면에서는 보안 정책 때문에 외부 시세 서버에 연결할 수 없어 시뮬레이션 데이터로 표시합니다. 저장소의 index.html 파일을 일반 브라우저(크롬, 사파리 등)에서 열면 실시간 데이터가 연결됩니다.

암호화폐 · Binance

BTCUSDT, ETHUSDT, SOLUSDT. 키 없이 연결되며, 가격과 현재 봉이 웹소켓으로 실시간 갱신됩니다.

나스닥 · Twelve Data

IXIC(나스닥 종합지수), NDX(나스닥 100). 무료 API 키가 필요합니다. twelvedata.com에서 가입하면 대시보드에서 키를 받을 수 있습니다. 무료 요금제는 분당 8회, 하루 800회까지라서 장중에는 2분마다 갱신하고, 시세가 거래소보다 늦을 수 있습니다. 키는 이 브라우저에만 저장됩니다.

그 밖의 종목(애플, 삼성전자, 코스피, 환율 등)은 시뮬레이션 데이터이며, 화면에 SIM으로 표시됩니다.
